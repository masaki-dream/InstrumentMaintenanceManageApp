# 🎸 Instrument Maintenance Management App

音楽機材（ギター・ピアノ等）のメンテナンス業務を管理する  
SPA + REST API構成のWebアプリケーションです。

---

# 📌 開発背景

私はアコースティックギターを5年間、ピアノを数ヶ月演奏してきました。

しかし、

- いつ弦交換をしたのか
- いつ掃除をしたのか
- 今どの機材がメンテナンス中なのか

を記録しておらず、管理が曖昧になっていることに不満を感じました。

この経験から、  
**「状態を明確に管理できるメンテナンス管理アプリ」** を開発しました。

---
